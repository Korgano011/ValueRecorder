The name of this app is value recorder. The target audience of this app is for people who think about recording quality of screen recording the least. Instead they want to focus on doing screen recordings using as little disk space as possible. The quality formats will be 120p, 240p, 480p, and 720p. In addition, there will be a built in mp3, and mp4 converter, so the user does not have to get a separate one. It will simplay convert the screen recordings to those formats instantly. There will also be an audio to text feature for the purpose of saving any audio to text for not taking purposes. There will also be the option for the user to save their recordings to a repository for future use.
